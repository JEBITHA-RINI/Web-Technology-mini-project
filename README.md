# My Personal Portfolio

A portfolio website built to showcase my journey as a Computer Science and Engineering student.

## 👤 About Me
I am a second-year Computer Science and Engineering student at Hindustan College of Technology, Salem. I am passionate about web development,
building creative software solutions, and continuously learning new technologies.

## 🚀 Features
- **Dark/Light Mode:** A toggleable theme for personalized viewing.
- **Interactive Music:** Integrated background music with a custom playback toggle.
- **Typing Animation:** Dynamic hero section displaying my core interests.
- **Responsive Design:** Fully optimized for both desktop and mobile devices.
- **Smooth Navigation:** Seamless scroll behavior for easy site exploration.

## 🛠 Tech Stack
- **Languages:**
HTML5,
CSS3,
JavaScript


## 📂 Project Structure
- `index.html`: Main structure and interactivity logic.
- `assets/`: Contains project-related resources.
- `bg-audio.mp3`: Background audio track.
